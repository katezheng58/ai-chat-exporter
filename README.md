# ai-chat-exporter
一个简单、本地化的 AI 聊天记录转换工具，支持多格式导出

### 初衷 
在日常使用中，我发现从不同 AI 平台（Claude, ChatGPT, Grok, DeepSeek）导出的对话数据难以直接阅读和编辑。为了提高效率，我在Gemini的帮助下开发了这个轻量化的本地工具。

### 核心功能 
**多格式兼容**：自动解析并标准化处理来自多个主流 AI 的 JSON/HTML 导出文件。

（Gemini的活动记录可以被识别，但顺序是混乱的）


**隐私保护**：100% 本地解析，数据不上传服务器，确保对话内容的私密性。


**灵活导出**：支持批量选中对话，并一键转换为 .doc (气泡美化/纯净模式)、.md、.txt 或 .json 格式。


### 使用方法 
从 AI 平台导出你的原始数据。

打开本工具，上传JSON/HTML文件。

在左侧列表搜索、勾选目标对话，选择格式并导出。
