# ai-chat-exporter
一个简单、本地化的 AI 聊天记录转换工具，支持多格式导出

## 初衷 
在日常学习和研究中，我发现将不同 AI 平台（Claude, ChatGPT, Grok, DeepSeek）的对话导出为排版美观的文档非常繁琐。为了提高效率，我开发了这个轻量化的本地工具。

## 核心功能 
多格式兼容：自动解析并标准化处理来自多个主流 AI 的 JSON/HTML 导出文件。

隐私保护：100% 本地解析，数据不上传服务器，确保对话内容的私密性。

灵活导出：支持批量选中对话，并一键转换为 .doc (气泡美化/纯净模式)、.md、.txt 或 .json 格式。


### 使用方法 
从 AI 平台导出你的原始数据。

打开本 HTML 工具，上传文件。

在左侧列表搜索、勾选目标对话，选择格式并导出。
